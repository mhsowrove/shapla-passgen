Private by design
Generation, QR rendering and strength analysis run locally. Passwords are never written to cookies, local storage, URLs or the offline cache. Only the optional breach lookup makes an external request. The hosting provider still receives normal page visits. Copied secrets may remain in your clipboard history; downloaded or printed credentials are yours to protect.
How strength estimates work
Generated password entropy counts the valid output space, including exclusions and required types. Passphrase counts include distinct-word choices and any length limit. Fixed separators and capitalization add no entropy. After manually swapping words the estimate is hidden because selection can introduce bias. Strength labels use 40, 60 and 80 bit thresholds. These labels do not guarantee safety or predict real cracking time.
The checker uses the bundled zxcvbn model to spot common patterns. It is an estimate, especially for non-English text and newer passwords. A negative breach result does not prove a password is safe. Use unique passwords, a password manager, and multi-factor authentication.
Offline use & deployment
After one complete visit over HTTPS, Shapla caches its static files for offline use. Passwords are never cached. Installation depends on your browser; on iPhone use Share → Add to Home Screen. Download the project and upload its contents to a GitHub Pages repository root. No backend, database or build step is required.
About this toolkit
Shapla Passgen is an independent implementation inspired by Passgen.co’s tools, with an original visual design. Its dictionaries and PIN filter differ from the reference. This edition has an English interface, seven word-list languages and selected multilingual Wi-Fi print labels. It is not affiliated with Passgen.co.
Word lists: Electronic Frontier Foundation, Uli Fouquet, Tango, drebs and victordargallo. QR library: Kazuhiko Arase. Strength checker: Dropbox zxcvbn. Pwned Passwords data: Have I Been Pwned / Troy Hunt (CC BY 4.0). Licenses and source details.
